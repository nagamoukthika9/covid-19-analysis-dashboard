# COVID-19 Analysis Dashboard

## Project Overview
This project analyzes COVID-19 data using Power BI to explore confirmed cases and trends over time.

## Tools Used
- Microsoft Power BI
- COVID-19 dataset

## Dashboard Features
- Total confirmed COVID-19 cases
- Confirmed cases by year
- Visual representation of COVID-19 trends

## Files Included
- `COVID-19 analysis dashboard.pbix` — Power BI dashboard file
- `README.md` — Project documentation

## How to View
Download the `.pbix` file from this repository and open it using Microsoft Power BI Desktop.
